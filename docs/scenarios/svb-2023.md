# SVB 2023 seven-engine boundary replay

This is FinReplay OS's first actual seven-engine integration flow. It reconstructs a deliberately
limited view available at 2023-03-08 18:00 UTC from seven filer-reported SEC XBRL facts in accession
`0000719739-23-000021`. It does not claim to reproduce every cause, decision, market price, funding
flow, regulator action, or subsequent outcome surrounding Silicon Valley Bank.

## Locked historical input

`scenarios/svb-2023/input-lock.json` contains exactly seven positive USD facts from the 2022
year-end frame: assets, deposits, stockholders' equity, held-to-maturity securities, HTM
unrecognized loss, available-for-sale securities, and AFS gross unrealized loss. Each record keeps
its SEC URL, accession, record identity, complete-response SHA-256, filing acceptance availability
time, retrieval time, and `reported` evidence label.

The lock is a minimal extracted subset, not the complete SEC response. Its raw-response hash
anchors the 2026 retrieval used for extraction, but the repository does not claim that the changing
Company Facts endpoint can reproduce those exact whole-response bytes forever. The accession facts
and their acceptance timestamps are treated as immutable events. Current FDIC and Treasury table
snapshots are excluded from the 2023 decision input.

## Actual engine flow

1. TimeVault appends the seven locked records into an empty in-memory database and queries them at
   the decision and economic times.
2. TrialCourt records a retrospective attempt, all six attacks, and a rejection. The attempt uses
   `p=1` because no valid inferential test exists, one regime slice, zero gross return, and explicit
   non-trading sentinel fields. It cannot silently become an eligible strategy.
3. MarketTwin creates three nodes and two exact reported portfolio edges, then applies a mechanical
   loss envelope. It is not causal contagion evidence.
4. ShockCompiler evaluates the two endpoints from zero to reported HTM unrecognized loss divided by
   reported HTM carrying value. The upper endpoint is inferred, not realized loss.
5. ExecutionLab has no historical market microstructure. It therefore uses a visibly simulated,
   normalized one-dollar reference-only instrument and conservative capacity/cost bounds.
6. CapitalAllocator combines the inferred loss bounds and simulated execution boundary. Under the
   declared non-positive return interval, the solver retains the all-cash model solution; this is
   not an investment recommendation.
7. ReplayStudio exports the seven content-addressed artifacts and five traceable claims as a static
   human- and machine-readable ReplayPack.

## Rebuild

```bash
python scripts/build_svb_replaypack.py
python scripts/verify_svb_replaypack.py
```

The deterministic pack fixes its build epoch and records `elapsed_seconds=0`. Actual two-rebuild
runtime, environment versions, byte comparisons, engine hashes, and the runner commit live in the
separate `verification/evidence/svb-seven-engine-rebuild.json` receipt. This separation prevents variable
runtime metadata from changing semantic pack identity.

The verifier starts from the committed input lock, reruns every engine twice, byte-compares both
directories with the committed pack, and byte-compares two deterministic ZIP files. Internal
reproduction is not external method review, hosted deployment, live trading, or user impact.

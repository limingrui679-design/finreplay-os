# Live-validated official source catalog

This catalog separates “an adapter retrieved and parsed an official current response” from “the
response proves what was knowable at a historical decision time.” The authoritative current
inventory is `verification/live/latest-summary.json`, regenerated by
`scripts/verify_live_receipts.py` after checking receipt and raw-response hashes.

| Adapter | Publisher product | Current temporal eligibility |
|---|---|---|
| `fdic.bankfind.financials` | FDIC BankFind financials | `latest_only` |
| `fdic.bankfind.institutions` | FDIC insured institutions | `latest_only` |
| `fdic.bankfind.locations` | FDIC institution locations | `latest_only` |
| `fdic.bankfind.history` | FDIC structure-change history | `latest_only` |
| `fdic.bankfind.summary` | FDIC historical aggregate summary | `latest_only` |
| `fdic.bankfind.failures` | FDIC failed-bank list | `latest_only` |
| `fdic.bankfind.sod` | FDIC Summary of Deposits | `latest_only` |
| `fdic.bankfind.demographics` | FDIC institution demographics | `latest_only` |
| `sec.edgar.submissions` | SEC EDGAR submissions index | immutable accession events |
| `sec.edgar.submissions_historical` | SEC EDGAR historical submission shard | immutable accession events |
| `sec.xbrl.companyfacts` | SEC EDGAR company XBRL facts | immutable accession events; exact or conservative acceptance bounds |
| `treasury.fiscaldata.debt_to_penny` | Treasury Debt to the Penny | `latest_only` |
| `treasury.fiscaldata.average_interest_rates` | Treasury average debt rates | `latest_only` |
| `treasury.fiscaldata.operating_cash_balance` | Daily Treasury Statement cash balance | `latest_only` |
| `treasury.fiscaldata.treasury_auctions` | Treasury securities auctions | `latest_only` |
| `treasury.fiscaldata.mspd_summary` | Monthly Statement of the Public Debt summary | `latest_only` |

The Fiscal Data adapters intentionally do not backdate a currently fetched value to its
`record_date`. The auctions table can announce a security before its future issue date; that is a
valid economic-timeline relationship, but the current API snapshot still becomes knowledge-eligible
only when retrieved unless an archived source artifact proves an earlier vintage.

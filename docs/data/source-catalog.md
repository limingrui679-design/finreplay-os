# Live-validated official source catalog

This catalog separates “an adapter retrieved and parsed an official current response” from “the
response proves what was knowable at a historical decision time.” The authoritative current
inventory is `verification/live/latest-summary.json`, regenerated by
`scripts/verify_live_receipts.py` after checking receipt and raw-response hashes.

The Fiscal Data adapters intentionally do not backdate a currently fetched value to its
`record_date`. The auctions table can announce a security before its future issue date; that is a
valid economic-timeline relationship, but the current API snapshot still becomes knowledge-eligible
only when retrieved unless an archived source artifact proves an earlier vintage.

The New York Fed adapters use distinct official Markets API product contracts, not nine aliases for
one series endpoint. Their economic, release, as-of, and `lastUpdated` fields are retained, but the
current endpoints do not by themselves preserve every value as originally published. All nine are
therefore knowledge-eligible only at retrieval time. Raw responses remain local and content
addressed. Redistribution requires the current New York Fed Terms of Use and source attribution;
reference rates carry additional notice and non-endorsement requirements.

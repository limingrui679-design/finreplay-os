# Quickstart

This path produces a deterministic ReplayPack from inputs bundled with the installed package. It
does not require source credentials or network access.

## Install from the repository

```bash
git clone https://github.com/limingrui679-design/finreplay-os.git
cd finreplay-os
python3.12 -m venv .venv
.venv/bin/pip install -e .
```

Confirm the CLI and catalogs:

```bash
.venv/bin/finreplay version
.venv/bin/finreplay adapter validate
.venv/bin/finreplay scenario list
```

## Run the flagship demo

```bash
.venv/bin/finreplay demo svb-2023 --offline --open
```

The command creates:

- `finreplay-demo/svb-2023/manifest.json`, the ReplayPack receipt;
- `finreplay-demo/svb-2023/report.json`, the structured compiled report;
- `finreplay-demo/svb-2023/index.html`, a standalone human-readable report;
- `finreplay-demo/svb-2023/README.md` and `checksums.sha256`; and
- `finreplay-demo/svb-2023.zip`, a deterministic archive.

Rerunning into the same destination succeeds only when every generated byte is identical. A
different pack cannot overwrite an existing destination.

## Inspect and reproduce evidence

```bash
# Resolve aliases and view the recorded hash, code revision, and input-lock identity.
.venv/bin/finreplay scenario show svb-2023

# Rebuild in a temporary directory and compare the result with the recorded pack SHA-256.
.venv/bin/finreplay scenario verify svb-2023

# Rerun every packaged scenario. This is slower but still offline.
.venv/bin/finreplay evidence verify --all-scenarios
```

## Build from your own specification

```bash
.venv/bin/finreplay replaypack build spec.json ./out/my-pack --archive ./out/my-pack.zip
.venv/bin/finreplay replaypack verify ./out/my-pack
.venv/bin/finreplay replaypack open ./out/my-pack
```

`spec.json` must validate as `ReplayPackSpec`; ReplayStudio then checks semantic invariants,
renders the fixed portable file set, verifies all hashes, and refuses mutation.

## Temporal boundary to remember

A source may pass current live validation yet remain `latest_only`. That proves a response was
available at the recorded retrieval time; it does not prove the exact value was available at an
earlier decision time. Use `finreplay adapter list --historical-only` to see the smaller eligible
subset.

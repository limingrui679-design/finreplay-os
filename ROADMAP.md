# Roadmap

The roadmap records bounded engineering goals, not promised outcomes or delivery dates.

## Current release line: 0.1 alpha

- Maintain one-command offline reproduction for all 30 counted scenarios.
- Keep the formal 30-adapter live-validation catalog distinct from scenario archive connectors.
- Publish installable package artifacts and deterministic release checksums.
- Give every evidence-site scenario a stable detail route and downloadable ReplayPack.
- Reduce contributor setup time with authoring guides, examples, and issue templates.

## Next evidence gates

- Receive a substantive independent reproduction or method review under the published protocol,
  resolve its findings, and obtain a same-reviewer recheck.
- Expand safe generic CLI fetch contracts only where upstream parameter models can be represented
  without hiding source-specific constraints.
- Add externally proposed scenarios or adapters through ordinary issues and pull requests.
- Measure documentation and demo usability only after consented, privacy-preserving user feedback
  exists.

## Later research directions

- More explicit uncertainty propagation across MarketTwin and ShockCompiler.
- Additional execution and capacity fixtures with publicly redistributable microstructure data.
- Versioned schema migration tools for long-lived ReplayPacks.
- Optional hosted comparison views that preserve local-first verification.

## Explicit non-goals for this evidence state

The roadmap does not claim production readiness, broker connectivity, institutional adoption,
external validation, investment performance, or real-world impact. Those claims require evidence
that this repository does not currently have.
